# Zenith Chrome Extension

**Zenith** is a premium, beautifully crafted new tab replacement extension for Google Chrome. It transforms your blank new tab page into a highly customizable, aesthetic workspace designed to boost productivity while looking stunning.

## ✨ Features

- **Glassmorphism UI:** A sleek, modern aesthetic with frosted glass elements that seamlessly blend with your chosen backgrounds.
- **Dynamic Workspaces & Layouts:** Add, resize, and freely position app shortcuts on a grid. Save different tile layouts (e.g., "Productivity", "Gaming") and switch between them instantly.
- **Customizable Backgrounds:** Choose from built-in high-quality wallpapers, dynamic CSS gradients, or upload your own images and looping video backgrounds.
- **Performance Mode:** Toggle animations off for a distraction-free and lightweight experience on older hardware.
- **Interactive Tutorial:** A beautifully integrated spotlight tutorial walks new users through all available features.
- **Smart Data Management:** All settings, layouts, and custom uploaded media are securely saved to your local browser storage—completely private, with zero external tracking.
- **Import & Export:** Easily back up your customized workspace and restore it across multiple devices.

## 🛠️ Technology Stack

Built purely with vanilla web technologies for maximum performance and minimum bloat:
- **HTML5 & CSS3** (Vanilla CSS with CSS Variables for themeing)
- **Vanilla JavaScript (ES6 Modules)**
- **Chrome Extensions API** (Manifest V3, `chrome.storage.local`, `chrome_url_overrides`)

## 🚀 Installation (Developer Mode)

1. Clone this repository or download the ZIP file.
2. Open Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked** and select the folder containing this extension's files.
5. Open a new tab to see Zenith in action!
